# 页面模式与设计决策

本文件用于选择布局和交互，组件签名仍从当前版本公开类型确认。先看业务应用已有页面与组件展厅，再选择下面的模式；示例中的业务数据、文案和回调由应用提供。

| 场景 | 优先组件 | 设计决策与验收 |
| --- | --- | --- |
| 列表、搜索、详情和编辑 | CrudPage；需要自定义编排时 DataTable、TableToolbar、Pagination | 标题/统计与搜索/操作分组；明确筛选后的空态和请求失败；窄屏允许表格内部滚动；排序状态、分页、返回位置可感知 |
| 数据录入、设置、资料 | Form 或原生 form + FormLayout、FormField、现有输入组件 | 关联字段分组，明确必填和单位；首次失焦/提交显示错误，修正更新；自动/显式跨列；失败保留输入，重复提交策略按真实业务 |
| 详情、确认、短流程 | Drawer、Modal、Confirm、Steps | 根据内容长度与前后文选择；标题、正文、操作区清楚；正文独立滚动，确认操作可见；焦点进入与关闭返回；保留输入与危险操作规则明确 |
| 多区域导航、移动端 | PageHeader、Breadcrumb、Tabs、AppBar、BottomNav、SafeArea | 导航名称对应真实任务；页签与路由导航分清；方向键和禁用项处理；移动端安全区域、触摸、返回与深链符合当前宿主 |
| 加载、无结果、失败和完成 | Skeleton、Empty、Alert、Result、现有消息容器 | 区分“没有数据”“筛选无匹配”“请求失败”“无权限”；说明原因和下一动作；重复实时播报、旋转图标和 toast 不能代替可恢复状态 |
| 上传与长任务 | 现有 storage 场景组件、进度与状态组件 | 大小/类型限制与服务端一致；区分上传、处理、完成和失败；取消/重试按幂等契约；真实外部效果未知时不能显示完成 |
| AI 对话、Markdown、代码和图表 | 已导出的 AI/图表场景组件 | 控制正文阅读宽度，代码/表格内部滚动；明确流式/加载/失败；渲染不可信内容走安全边界；图表图例、单位、色彩外的信息和文本摘要可读 |
| 官网与帮助 | 现有布局、内容与 guide 能力 | 官网按内容与行动组织层级，帮助按问题和步骤组织；使用真实文案/素材，语言展开和阅读宽度适合目标端 |

## 视觉约定如何落到实现

- 语义色用 `base-*`、`primary`、`success`、`warning`、`error` 等当前主题变量，焦点沿 `--hai-focus-color`；使用已编译主题白名单与公开 theme 工具。
- 共享间距、圆角、动效、触摸区域沿 theme/design tokens；表格使用现有 `density`。调整密度以任务和目标设备为依据，不为每个组件新增同名配置。
- 标题、说明、字段标签、数值、状态有明确层级；后台外壳使用可用宽度，正文保留阅读宽度。flex/grid 子项考虑 `min-width: 0`；长链接/标识符可换行，代码可内部滚动。
- 操作优先级按业务决定；按钮文案说明动作，图标按钮有可访问名称。关键操作不只依赖颜色或 hover。
- 动效说明变化或空间关系，尊重 `prefers-reduced-motion`。新动效的加载、取消和最终状态都要可验证。

## 页面方案最小示例

“成员列表”沿现有 CrudPage 实现：用户任务是查找成员、查看详情和修改获授权字段。顶部放名称/数量及主要操作，筛选与排序放工具栏，表格使用现有 density；窄屏内部滚动。记录初次加载、请求失败重试、无成员、筛选无结果、提交失败保留输入和缺权限状态。验收覆盖操作后的真实数据、键盘排序/页签、390px 手机、1440px 桌面、英文长名称和明暗主题。具体字段/权限来自业务需求，不从组件示例推断。
